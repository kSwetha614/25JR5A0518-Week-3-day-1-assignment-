1.What is the slope: The slope is the value shown in model.coef_. It represents how much the output (Marks) changes when the input features increase by one unit.

2.What is the intercept: The intercept is the value shown in model.intercept_. It is the starting value of the prediction when all input features are zero.

3.What do they mean: The slope shows the relationship between features and the target variable. Positive values increase the prediction, while negative values decrease it. The intercept acts as the base prediction of the model.
